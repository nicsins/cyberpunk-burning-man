# Dragon & Panda Neon Plaza

Third-person client showcase + light void shooter for **dragonandpanda.com**.

## Run locally

Open `index.html` from a static server (needed for ES modules):

```bash
python3 -m http.server 8080 --directory /home/workdir/artifacts/dragon-panda-site
```

Then visit http://localhost:8080

## Loop

1. Pick Panda or Dragon.
2. Talk to five NPCs, stand four pads, print one field app.
3. Hostiles (max 10) collect kindling and try to light the effigy. Stop them.
4. Call drone (`X`) or wait for NPCs to douse an early fire.
5. When ready hits 100%, `E` at the Man to burn it.
6. Client terminal opens in the afterglow.

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Shift | Sprint |
| Space / Ctrl | Fly up / down while mounted |
| LMB | Pulse gun |
| G | Throw boom |
| F | Ride / dismount drone |
| R | Ride / dismount dragon |
| Q | Cloak app |
| J | Jammer app |
| X | Drone water run |
| E | Talk / pad / light |
| C | Field bench |
| P | Input mapper |
| M V H | Gallery / vision / help |

Xbox defaults: left stick move, right stick look, A use, RT shoot, B boom, LB/RB mounts, X cloak, Y jammer, LT douse, Menu opens mapper.

Remap: highlight a row, press the new control, check the capture box, Save. Keyboard/mouse and Xbox each keep their own saved map.

Not a sweaty shooter. Few enemies, slow lighting steps, stealth tools, mounts.
