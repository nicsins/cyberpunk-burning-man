# Cyberpunk Burning Man Ω HD

Interactive 3D Black Rock City 2077 with detailed NPC sprites, collectible items, Zero-Point Energy Generators, x402 token economy, auction house, and Omega Suite stations.

**Live:** https://cyberpunk-burning-man.vercel.app

## Features
- Detailed photoreal cyberpunk NPC sprites (unique per character)
- Dragon & Panda player avatars
- Textured Playa ground
- Collectible item sprites with glow
- ZPEG generators that mint tokens
- Quests, auction, Omega apps (x402, FairForge, Vonnect, Creator of All)

## Controls
WASD · Mouse look · E interact · I inventory · Tab Ω Panel · 1/2 avatar switch
