# Cyberpunk Burning Man Ω HD

Interactive 3D Black Rock City 2077 with detailed NPC sprites, collectible items, Zero-Point Energy Generators, x402 token economy, auction house, and Omega Suite stations.

**Live:** https://cyberpunk-burning-man.vercel.app

## Features
- Detailed photoreal cyberpunk NPC sprites (unique per character)
- Dragon & Panda player avatars
- Textured Playa ground (map) + tech-plate Omega station holograms
- Collectible item sprites with glow (geometric fallback if a texture fails)
- Auto-pickup on contact · carry/drop with Ctrl
- Proximity NPC talk (stand still ~2s) · E for optional instant talk
- ZPEG generators that mint tokens
- Quests, auction, Omega apps (x402, FairForge, Vonnect, Creator of All)
- Pointer-lock FPS look with Click-to-resume overlay

## Controls
- **WASD** — move
- **Mouse** — look (click canvas to lock pointer; **Esc** unlocks intentionally)
- **Auto-pickup** — walk into glowing collectibles (no E required)
- **Ctrl** — drop carried / last-picked item near you
- **Stand still ~2s** near an NPC — open dialogue (move cancels)
- **E** — optional instant talk / stomp fires / stations
- **F** — fly (Dragon)
- **R** — frost breath (Dragon) / suppress drone (Panda)
- **LMB** — attack
- **I** / **Tab** — inventory & Ω Panel
- **1** / **2** — switch Dragon / Panda
- **H** — toggle help
